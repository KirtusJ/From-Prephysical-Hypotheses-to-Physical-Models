## W4 is more than wording: a start in both rails reads chi(c/a)

Checked by hand by the director. Start in the equal superposition of rails at site 0 and read port (1, well 1, R).
The two words are a right step from R (gain a) and a right step from L (gain c), so the probability is
proportional to |chi(a) + chi(c)|^2. Two carriers in C2 x C4 with the same chi(B) = i and chi(H) = -1:
a = c = 1, b = g, d = zg gives 4; a = b = 1, c = g, d = zg gives |1 + i|^2 = 2. Under a sharp start they agree on
every event (Prop 1). So the statement "position-mask events never read chi(a), chi(c)" is a statement about the
class of preparations, and the list of what is undetermined is shorter once a rail superposition can be prepared.
Whether such a preparation is available from the admitted operations is not settled here; it is a question for
OP-30 and for Director G's preparation lemmas.
