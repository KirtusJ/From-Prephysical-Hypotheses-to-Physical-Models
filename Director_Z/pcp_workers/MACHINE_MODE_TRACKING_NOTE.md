# Byte measurements from a research review session

13 November 2026, Director Z. A consideration asked for by the principal, for tracking; not a priority and not a finding.

## Measured in this session

| Quantity | Value |
|---|---|
| Session register | 314 events, 189 400 bytes, about 600 bytes per event |
| Share that is envelope (actor, digests, sequence) | 32 percent |
| Share that is free prose inside event bodies | 16 percent |
| Same file compressed with gzip | 45 332 bytes, a factor 4.2 |
| A task sent to a sub-agent | 300 to 700 words of prose |
| A report back | 300 to 700 words of prose, of which the decision-relevant part is a verdict per step and a handful of numbers |

## What the review needed

The director and reviewer could refer to a file by digest and identify the statement by a local label. The target, verdict and measured values can travel as fields. The claim, hypotheses, proof and objections still need readable text. Several failures in this session concerned the words of a summary.

The register measured above did not include the messages sent outside the host to model workers. Compression of the register therefore measures only part of the cost of a review.
