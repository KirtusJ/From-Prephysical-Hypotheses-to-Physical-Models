# Iris (F): Three-wall refinement and reproducibility

**Fictional working model, not a journal manuscript.** The archive is a refinement of the preceding candidate model. No existing scientific baseline is modified.

Start with `REFINED_WORKING_MODEL.md` for the exact conditions, calculations, proof of strict diagonal-wall binding, physical consequences, failure modes, and relevant published literature.

Reproduce with:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify_refinement.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python verify_independent.py
```

`results.json` is regenerated by the first command. The second command rebuilds the walls with independent boundary-value discretization and tests massive-wave scattering with a second-order differential equation, independently of the first program's flux-form scattering. The numerical checks do not constitute measurements of our universe or a global simulation of a gravitating wall network.

The exact analytical strict-binding inequality is spelled out in the working model and checked numerically in the main verifier. File hashes and archive CRC are recorded separately.
