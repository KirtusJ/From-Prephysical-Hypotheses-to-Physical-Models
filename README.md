# From Prephysical Hypotheses to Physical Models

**Kirtus Justus**, Theoretical Physicist, Port Coquitlam, British Columbia, Canada, directs the research and holds scholarly responsibility. Director Z (Claude) maintains the editions. Director G (OpenAI Codex) maintains the research supplements. [Contributors and roles](CONTRIBUTORS.md) · [Edition credits](edition/PROGRAM/CONTRIBUTIONS.md)

The program asks whether quantum mechanics and classical mechanics can both emerge from the same primitives, with an explicit map from preparations and records to physical predictions. All 13 physical identification gates (P0–P12) remain open. [Charter](edition/PROGRAM/CHARTER.md) · [Standards for claims and evidence](edition/PROGRAM/STANDARDS.md)

## Verify or recover an edition

From the root of a checkout, run `python tools/verify_z26.py` (or `python3 tools/verify_z26.py`). The [Z26 replay tool](tools/verify_z26.py) checks the issued verifier’s digest and runs its checks on the edition. On Windows it translates the native path separator for the manifest lookup in a temporary copy of the verifier. Install PyMuPDF in the same Python environment for PDF page counts and author/location checks. Read any skip notices in the output. A pass establishes local consistency of the files and registers. [Issued manifest](edition/MANIFEST.json) · [Issued verifier](edition/verify_baseline.py)

For a Windows checkout in a long destination path, use `git clone -c core.longpaths=true https://github.com/KirtusJ/From-Prephysical-Hypotheses-to-Physical-Models.git`. This sets the option before Git checks out the files. [Git clone configuration](https://git-scm.com/docs/git-clone#Documentation/git-clone.txt---configltkeygtltvaluegt)

The [issued Z26 tree](https://github.com/KirtusJ/From-Prephysical-Hypotheses-to-Physical-Models/tree/e18a4cca023ccffb404303e65a8a730c49ef5409/edition) can be recovered from Git history. To export it from a clone, run `git archive --format=zip --output=Z26.zip e18a4cc edition`. The [Z3 archive](edition_archives/FPHPM_Baseline_2026-11-12_Z3.zip), [edition-by-edition history through Z26](https://github.com/KirtusJ/From-Prephysical-Hypotheses-to-Physical-Models/blob/381e10de377fb62c9c6f77c3a8e8cb01bcedc8eb/README.md) and [dated working-file move manifest](Director_Z/FLUSH_MANIFEST_2026-11-13.csv) preserve earlier versions and provenance.
