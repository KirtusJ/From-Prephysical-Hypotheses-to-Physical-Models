# From Prephysical Hypotheses to Physical Models

**Kirtus Justus**, Theoretical Physicist
Port Coquitlam, British Columbia, Canada

This repository holds the baseline editions of the research program as archives, with the documents of the latest review sessions beside them for direct reading. The program's aim, structure and standards are in `PROGRAM/CHARTER.md` and `PROGRAM/STANDARDS.md` inside each edition. No edition claims a physical ontology; no gate of the program's gate map is passed.
