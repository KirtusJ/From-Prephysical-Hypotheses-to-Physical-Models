CLAIM A (PROVED). D_h line or ring, any q>=1. Suppose (Eq) with k=2 holds at every site x for the pairs
(U,V)=(m,0) and (0,m), for every m in N^C (only these "one-sided" pairs are needed), and y->F_y(m) bounded below
(automatic on rings). Then F_y(m) does not depend on y.
Proof. Fix m; A^j_x=F_(x,R)(T^j m), B^j_x=F_(x,L)(T^j m), j in Z/q (T^q=1). (Eq) at (T^j m,0),(0,T^j m):
 (1) A^j_{x+1}+B^j_{x-1}=2A^j_x,  (2) A^j_{x+1}+B^{j+1}_{x-1}=2B^j_x  [(0,V): U+TV=T V].
For w with w^q=1 put a_x=sum_j w^{-j}A^j_x, b_x=sum_j w^{-j}B^j_x. Then sum_j w^{-j}B^{j+1}=w b, so
 (1') a_{x+1}+b_{x-1}=2a_x, (2') a_{x+1}+w b_{x-1}=2b_x.
w=1: a=b, a_{x+1}+a_{x-1}=2a_x, a affine in x; ring: periodic => constant; line: a=sum_j A^j bounded below => constant.
 Line: each A^j_x = a - sum_{i!=j}A^i_x is then bounded above too; likewise B^j. So all a_x,b_x bounded (all w).
w!=1: (2')-(1'): b_x=a_x+((w-1)/2) b_{x-1}; with v_x=(a_x,b_{x-1}): v_{x+1}=M v_x, M=[[2,-1],[1,(w-1)/2]],
 det M=w (invertible), tr M=(3+w)/2. If M had eigenvalue l with |l|=1: other is w/l, l+w*conj(l)=tr, i.e.
 2cos(th-ph/2)e^{i ph/2}=(3+e^{i ph})/2 (l=e^{i th}, w=e^{i ph}); multiply by e^{-i ph/2}: RHS=2cos(ph/2)-i sin(ph/2)
 must be real => sin(ph/2)=0 => w=1, contradiction. So |l1|>1>|l2| (|l1 l2|=1). Line: v bounded on Z => both
 components 0. Ring: v_{x+N}=v_x, (M^N-1)v=0, l^N!=1 => v=0. So a=b=0 for all w!=1.
Fourier inversion: A^j_x = (1/q) sum_w w^j a^{(w)}_x = (1/q) a^{(1)} = constant P, B^j_x = P too. QED.
(For q=2, w=-1: M has char poly l^2-l-1, the paper's golden matrix up to change of variables.)
