Run this from a research checkout containing commit `898ac27243cbf44168be88b332f899b4c3f16223`. The supplied registration binds the exact Python program, Director Z’s earlier rank data, and the output of the gain-orbit calculation. Fetch the commit first if using a shallow checkout. The runner checks the manifest pin, looks up each regular Git blob at its named commit, and copies only the program and declared inputs into a fresh temporary tree. It runs the reviewed Python entry point there with a fresh output-directory argument. The expected output stays in the parent process. The receipt on stdout gives both output digests and sizes, the first differing byte on mismatch, the child exit code, and runtime details. A nonzero child exit fails the replay even if the child wrote matching bytes. Exit 0 means a byte match, 5 means a failed check, and 2 means invalid setup. This example produced 12,204 bytes at SHA-256 `2de35d2d7443757834c06fe9ff294584d1480a741b5571feffb685052f7e0516`. [Runner](replay_science.py) · [Failure controls](test_science_replay.py)

Preserve the manifest bytes across checkouts, including LF line endings for the two examples here. The program must take one output directory and produce the basename of the chosen archive there. Keep the manifest’s byte digest with the commission before the rerun. A changed program, input or standard of comparison then has its own identified registration.
