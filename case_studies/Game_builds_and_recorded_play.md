## Reproducing the inspection

Run `python -B case_studies/game_artifacts/inspect_game_files.py <originals-directory>` from the repository. It checks every supplied file against the public pins, reads each ZIP through its CRC checks, validates member paths, inventories the regular members and source tarballs, checks PWAD directory bounds, and compares the save to the memory record. Pass `--inventory <new-local-json>` to retain every member digest and WAD lump name. The original and optimized-Python inspections agree. The full local receipt is in `Session/Case_studies/2026-11-14_game_artifacts/full_inventory.json`, SHA-256 `8ac61c7e46930c2ca92185d9df7ba75d7fe2d507f55808da241b77f91d044220`. A source-package signature was not supplied.

The Rust checks used Rust 1.91.1, `cargo test --offline --locked -p night-post` and `cargo test --offline --locked -p bellweather` in the corresponding extracted workspaces. A Codex worker ran the Rust and WebAssembly checks. A second worker decoded the recordings. A third checked the archive contents, the Doom slot, and the four regenerated assets against the supplied bytes. These are in-project technical checks.
