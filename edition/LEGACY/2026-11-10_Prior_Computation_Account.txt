D. Joint calibration and sampling uncertainty

  Computational_Material/Joint_Calibration/verify_joint_calibration.py
  Computational_Material/Joint_Calibration/Joint_Calibration_Results.json

The program records 11,807 successful predicates. These include 11,025
separated-rectangle and target-grid cases, 5,321 constructive feasible
witnesses, binomial coverage controls on the specified finite grid, an adverse
zero-radius example and exact outward tail inversion.

Binomial controls cover n=1,...,12, p=i/20 for i=0,...,20, at three stated
error levels. They are not a proof for all real p; that proof is in the study.
The numerical interval construction uses arbitrary-precision integers and
Fraction arithmetic. Forty bisections give endpoint brackets at most 2^-40
wide. Exact tail inequalities and outward endpoint choices are retained.

The counts 85/100, 15/100 and 85/200 are hypothetical. Under the declared
binomial marginals and a preassigned total error of 0.05, the displayed
outward target interval is [0.128936, 0.651769]. Its interpretation depends on
the stated calibration anchors, shared response law and sampling contract.
The uniform whole-identified-set guarantee is a mathematical implication,
not a finding that an apparatus satisfies those conditions.

4. Reproduction commands

Use the package versions stated above to reproduce the recorded environment.
The following commands assume a shell with Python available as python.

Create a destination for new outputs:
  mkdir -p Run_Results

Run the graph certificate:
  python -I -B Computational_Material/Instrument_and_Graph_Examples/checks/graph_certificate.py --output Run_Results/graph_certificate.json

The causal-readout program writes RESULTS.json beside itself. Copy its program
and input into a new directory before running:
  mkdir -p Run_Results/Causal_Readout
  cp Computational_Material/Causal_Readout/verify_causal_readout.py Run_Results/Causal_Readout/
  cp Computational_Material/Causal_Readout/TRANSPORT_CERTIFICATE.json Run_Results/Causal_Readout/
  python -I -B Run_Results/Causal_Readout/verify_causal_readout.py > Run_Results/Causal_Readout/run.log

Run the four finite-example suites:
  python -I -B Computational_Material/Finite_Examples/verify_mathematical_examples.py --output Run_Results/Mathematical_Examples_Exact_Checks.json
  python -I -B Computational_Material/Finite_Examples/verify_operational_results.py > Run_Results/Operational_Exact_Checks.json
  python -I -B Computational_Material/Finite_Examples/verify_finite_signs.py > Run_Results/Finite_Sign_Exact_Checks.json
  python -I -B Computational_Material/Finite_Examples/verify_coverage_additions.py > Run_Results/Coverage_Additions_Exact_Checks.json

The first finite-example program writes to its --output path and prints a short
status to standard output. The other three print their complete JSON results to
standard output. No additional data file is required by these four programs.

Successful completion means that the program reached its result output without
a failed explicit check or an execution error. Inspect the recorded status,
predicate count and mathematical scope as well as the process exit status.
Changing software versions can change formatting or numerical decimal
renderings; byte identity is the reported result for the recorded environment,
not a general promise across environments.

5. Remaining computational scope

Other archived programs, recorded outputs and certificates included with the
articles were retained for inspection and reproduction. They were not rerun
for this preparation. In particular, the two original reruns above do not
establish fresh execution of every calculation in the same articles, such as
the graph threshold-sampling guarantees, interval sweeps, full-density
integrals, calibration-rank calculations, or a separate 6,758-record
calculation. Each such claim retains the proof and computational qualifications
given in its own article.

A stored expected output is not itself evidence that the corresponding program
was newly executed. Agreement with a stored output establishes reproducibility
of that calculation under the stated inputs and environment; it does not
validate every assumption used to connect the calculation to an unrestricted
theorem or a physical experiment. The mathematical arguments and their explicit
observation, calibration, sampling, and resource assumptions remain essential.
