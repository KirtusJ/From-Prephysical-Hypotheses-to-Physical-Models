Consider every directed graph on the three vertices 0, 1, 2 in which each vertex has exactly d outgoing arcs to distinct targets; an arc from a vertex to itself (a loop) is allowed, and there is at most one arc from a given vertex to a given target. Call a non-empty set W of vertices closed if every arc that starts in W also ends in W. A closed set is good if it contains a vertex z that has at least two different predecessors lying in W (a predecessor of z is a vertex with an arc to z; z itself counts if it has a loop). For d = 2 and then for d = 1, count: G, the number of such graphs; P, the number of pairs (graph, closed set); B, the number of pairs whose closed set is not good; H, the number of graphs that have at least one closed set that is not good. Answer in exactly this format on one line, d = 2 first: G2=.. P2=.. B2=.. H2=.. G1=.. P1=.. B1=.. H1=..
