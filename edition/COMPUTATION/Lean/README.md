# Lean proofs

Three files for Lean 4.12.0, core library only (no Mathlib). Check each with `lean <file>`; exit code 0 and the line naming the axioms `propext` and `Quot.sound` is a pass. They prove the recursion of G10 Theorem 5.1 and G10 Lemma 5.4 with integer values. Written by a sub-agent of the fourth Director Z session and rechecked in that session. Nothing else in the collection is formalized.
