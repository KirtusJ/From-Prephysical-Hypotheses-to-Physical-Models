# Lean proofs

Four files in this folder need Lean 4.12.0 and the core library only: check each with `lean <file>`. The folder `Mathlib/` holds eleven files for Lean 4.12.0 with Mathlib v4.12.0, with the lakefile, toolchain file and manifest of the project they were checked in: place the files in a folder `FPHPM/` beside the lakefile, run `lake exe cache get`, then `lake env lean FPHPM/<file>`. A pass is exit code 0 and a line naming only the axioms `propext`, `Quot.sound` and, with Mathlib, `Classical.choice`. The files prove algebraic lemmas used in paper G10: the recursion of Theorem 5.1 (SignedLineRecursion), Lemma 5.4 (ParallelogramInt, ParallelogramGroup, Parallelogram), the convexity step of Theorem 5.2 (PowerSumConvexity), the character step of Theorem 5.8 (CharacterIndependence), the reductions of Proposition 5.10 (ThreeLaw, FourLaw), the law M_k of Theorem 5.11 (MkSmall, MkGeneral), certificates for Theorem 5.12 (VslCertificates), two steps of Theorem 5.16 (GaugeBlock), three steps of Theorem 5.18 (MultisetBlock); and the sequential-projection inequality used by Director G (SequentialProjections). All fifteen files were rerun at the comb after edition Z17. No statement about gain digraphs, walks or events is formalized. Written by sub-agents of the fourth Director Z session and rechecked in that session.
